## Welcome

Thank you for helping us test the Student Placement prototype. You act as a **Placement Coordinator**. There are five short scenarios. Each one uses data that is already in the prototype, so you do not need to prepare anything.

We test the prototype, **not you**. If something is hard to find or does not make sense, that is exactly what we want to learn.

## Before you start

1. Use a desktop browser with a window about 1440 pixels wide.
2. Log in with the access code you were given.

![The login screen](/guide/start/01-login.png)

3. The data is **mock data**. Nobody is contacted, and nothing leaves your browser.

## What is saved and what is not

| Saved in this browser | Lost when you reload the page |
|---|---|
| Studies, programs and emner | Student placements |
| Entities and their contacts | Priority lists and applications |
| The imported students and tags | Study Admins |

> **Do not reload the page in the middle of a scenario.** Scenarios 4 and 5 build on each other, so do them in one go.

## The scenarios

1. [Settings: studies, programs and Study Admins](#/guide/ts-01)

## How to give feedback

Think aloud while you work: say what you expect before you press something. When you notice a problem, tell us the scenario and step number, for example "TS-03, step 4", and which kind it is:

- **Bug:** something is broken.
- **Confusion:** it works, but you did not understand it.
- **Wish:** something you miss.

## Good to know

- There is no student side. When a scenario needs a student's application, the coordinator submits it on the student's behalf.
- Places never block you. If you place more students than there are places, you see "over by N".
